# NLP Sentiment Analysis & Text Processing Pipeline

A comprehensive Python repository demonstrating core Natural Language Processing (NLP) techniques, from raw text preprocessing to machine learning classification.

## 🛠 Tech Stack
* **Python 3.x**
* **NLTK** (Tokenization, Stemming, Lemmatization)
* **spaCy** (POS Tagging, Named Entity Recognition)
* **Scikit-Learn** (CountVectorizer, Multinomial Naive Bayes, Pipelines)
* **Pandas & NumPy**

## 🚀 Modules Included
1. **Text Preprocessing:** Tokenization and comparative evaluation of Stemming (Porter) vs. Lemmatization (WordNet).
2. **Linguistic Analysis:** Part-of-Speech (POS) tagging and frequency analysis with spaCy.
3. **Information Extraction:** Named Entity Recognition (NER) for extracting dates and geographical locations (`GPE`).
4. **Sentiment Classifier:** End-to-end classification pipeline combining Bag-of-Words and Multinomial Naive Bayes.
